<div align="center"><b>Advanced Scientific calculator</b></div><br>
It is a web-based application with a frontend built using HTML, CSS, and JavaScript, and a backend powered by Flex, Bison, and Python to handle complex mathematical parsing and computation. It supports advanced operations beyond basic arithmetic, including trigonometric, logarithmic, and algebraic functions. A key use case is providing students, educators, and professionals with a reliable tool for solving complex equations and performing scientific calculations directly in the browser, while ensuring accurate backend processing through compiler-based parsing techniques.<br> 
<b>Tools & Libraries: HTML, CSS, JavaScript, Python, Flex, Bison, Notepad, Vs Code<br>
Frontend : Html ,CSS ,JS <Br>
Backend : Flex ,Bison ,Python( connect front end with backend )<br><br>
